# Changelog

## 1.1.0rc1 — 2026-10-28

First GitHub release candidate of the host-integrated OSS engine. This preview
targets API v1; it does not declare the broader stable workflow checklist complete.

- Public Python API v1 for caller-configured data, evaluation, training, runs
  and artifacts, with explicit host-owned configuration, authority and stores.
- Native Apple-silicon MLX SFT and GRPO integration with pinned separate runtime
  profiles, immutable prepared inputs, saved-adapter reload verification and
  five-role artifact delivery.
- Opt-in native numeric progress, confirmed cancellation and authenticated cold
  reconciliation after caller loss, qualified on the bounded M4 fixture.
- Representative conversation/tool SFT preparation and separately admitted
  saved-model evaluation examples.
- Developer installation/release guidance and reconciled qualification status.

See [release notes](docs/releases/1.1.0rc1.md) for exact source identities,
qualification limits, distribution contents and installation instructions.
