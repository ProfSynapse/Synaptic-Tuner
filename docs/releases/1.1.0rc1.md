# Synaptic Tuner 1.1.0rc1

First scoped OSS engine release candidate, targeting the Python API v1 contract.
This is a GitHub prerelease for application developers. It is not the broader
stable workflow release described in the [historical gate](../plans/stable-v1-release.md).

## Included

The engine exposes caller-configured data generation/validation, evaluation and
report comparison, training, retained runs, and artifact operations. The host
supplies the selected backends, configuration, credentials, authorization and
durable storage. An exported facade is not universal backend qualification.

The native Apple-silicon path supports SFT and GRPO with exact profile/source/
runtime/model/input bindings, verified saved adapters and five artifact roles.
An explicit lifecycle policy and independently authenticated host authority add
numeric progress, cancellation and cold reconciliation. Legacy synchronous
selections keep those lifecycle capabilities off.

## Install

Download the wheel, source distribution and `SHA256SUMS` from the
[v1.1.0rc1 release](https://github.com/ProfSynapse/Synaptic-Tuner/releases/tag/v1.1.0rc1).
Keep both archives beside the checksum file before verification:

```sh
sha256sum --check SHA256SUMS
python -m venv .venv
.venv/bin/python -m pip install ./synaptic_tuner-1.1.0rc1-py3-none-any.whl
.venv/bin/synaptic --help
```

On macOS use `shasum -a 256 --check SHA256SUMS`; on Windows compare each archive
with `Get-FileHash -Algorithm SHA256` and use `.venv\Scripts\python.exe`.
The base package needs Python 3.10+ and does not install MLX, Torch, Modal or a
model. Effectful runtimes have separate exact Python/dependency requirements.

The wheel is a library/base-CLI distribution, **not a self-contained training
runtime**. It includes reviewed schemas/configuration assets; scripts, host
examples and runtime build declarations require the matching source checkout
at the release tag. The built sdist contains library build inputs, not the full
checkout workflow. Host manifests must explicitly allow `>=1.1.0rc1,<2` when
using this preview. See the [developer guide](../development.md) for host
composition, checkout use and validation. No PyPI publication is part of this
release, so use the attached exact wheel rather than `pip install synaptic-tuner`.
